## Sources (details, terms and checks: `playbook/12-sources.md`)
- **No statewide food-license list, no statewide inspection data, no official grade.** Only two cities publish in bulk:
  - **Cincinnati Health Department** (data.cincinnati-oh.gov rg6p-b3h3, Public Domain, daily): one row per cited violation. Since the
    City's 2024 system each visit carries the City's own result ("Approved - No Violations", "Approved - Minor Violations",
    "Approved - Violations Abated", "Not In Compliance"); shown word for word with the violations cited on the inspection's first visit.
    Older visits carry violation states, not results: not shown. No critical/non-critical flag: never say "critical". Records through
    = fetch date minus 10 days (`official.CIN_THROUGH`).
  - **Columbus Public Health** (maps2.columbus.gov Health/MapServer/3, CC0, nightly): every permit with business type and the City's own
    status ("Standards Met", "Under Enforcement", "Closed for Violation"). No dates or counts. `PERMIT_ENTERED_DATE` 2001-03-16 is an
    import stamp: never shown. Its decadeonline.com history links time out from scripts: check in a browser before linking.
- Search only / blocked: myhealthdepartment (bot check), Franklin County (Accela, records request), Dayton-Montgomery (crawl needs Nick's
  yes), Cleveland (nothing online), Liquor Control (export disabled: "serves alcohol" unknown), property values (no license).
- Calibration inside Columbus and Cincinnati city limits: Meta + Google-open 85% / 83%, Meta ≥0.95 85% / 85%, Foursquare-only 18% / 11%.
